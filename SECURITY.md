# Security policy

Mellow edits local files and will eventually integrate with AI/tool providers, so filesystem and execution boundaries are security-sensitive.

Please do not open a public issue for a vulnerability that could cause unintended command execution, data disclosure, permission bypass or destructive file modification. Report it privately to the Ritru Labs maintainers through GitHub's private vulnerability reporting once enabled for the repository.

The current M0.x series is pre-release software. Back up important files before using it on production systems.
